A travel poster for **VELMORA** — a desert valley where one giant crystal
spire rises out of the dunes at dusk. Violet sky melting into amber at the
horizon, a low sun, and a tiny caravan crossing the ridge for scale.

`main.py` draws the whole poster with PIL only (no network, no downloaded
assets) and writes it to `/output/entry.png` (1024×1024, PNG).

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
